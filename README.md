# XR Space

אפליקציית אנדרואיד למשקפי XREAL Air / Air 2 / Air 2 Pro, בדומה ל-Nebula:

- **מסך קבוע במקום (3DoF)**: החלונות נשארים במקומם כשמזיזים את הראש. המידע מגיע מחיישן התנועה של המשקפיים דרך USB.
- **כמה חלונות צפים**: אתרים, מסך בית ושיקוף של מסך הטלפון.
- **מסך מעוקל**: שליטה בעיקול, במרחק ובגודל של כל חלון.
- **מסך בית**: אתרים, חיפוש ורשימת האפליקציות שבטלפון.
- **הטלפון כשלט**: משטח מגע, מקלדת וכפתורי שליטה.

## הורדה
https://github.com/idanamos-jpg/idana/releases/latest/download/XR-Space.apk

## התקנה
1. פותחים את הקישור בטלפון ומורידים את הקובץ.
2. פותחים את הקובץ ומאשרים "התקנה ממקורות לא ידועים".
3. מחברים את המשקפיים. מאשרים גישת USB ל-XR Space, ואפשר לסמן "השתמש כברירת מחדל".
4. אם סמסונג מציעה DeX, בוחרים בשיקוף מסך או סוגרים את ההצעה. בהגדרות של DeX כדאי לכבות הפעלה אוטומטית בחיבור מסך.

## שימוש
- **אצבע אחת**: הזזת הסמן. **הקשה**: לחיצה.
- **לחיצה ארוכה וגרירה**: הזזת חלון.
- **שתי אצבעות**: גלילה. **צביטה**: שינוי גודל החלון.
- **◎ מרכוז**: הכיוון שאליו מסתכלים עכשיו נקבע כמרכז.
- **"מסך קבוע במקום"** מסומן: מצב 3DoF. לא מסומן: המסך נעול לראש, ו"חלון הבא" עובר בין החלונות.
- **⚙ הגדרות**: אם התנועה הפוכה, מסמנים "הפוך כיוון". יש שם גם כיול חיישן ושדה ראייה.

# Lumo

אפליקציה שנייה בריפו: שולחן עבודה בסגנון DeX על משקפי ה-XREAL. השליטה בגודל המסך הווירטואלי ובמרחק שלו נעשית מהטלפון.

- **גודל המסך**: אלכסון 10″–150″, ויחס 16:9 / 16:10 / 21:9 / 32:9 (אולטרה-רחב).
- **מרחק**: 0.4–5 מ׳. ככל שהמסך רחוק יותר, הוא תופס פחות משדה הראייה. מה שמחוץ למסך שחור, ולכן שקוף במשקפיים.
- **גובה**: אפשר להזיז את המסך למעלה או למטה.
- **מצבים מוכנים**: נייד 15″, מסך 27″, רחב 34″, אולטרה 49″, טלוויזיה 65″, קולנוע 150″.
- **שולחן עבודה במשקפיים**: שורת משימות עם שעון, אפליקציות מוצמדות, חלונות פתוחים ותפריט התחלה.
- **חלונות**: אפליקציות נפתחות בתוך המסך הווירטואלי, במסך מלא, בחצי ימין, בחצי שמאל או במרכז. כשמשנים גודל או מרחק, החלונות מסתדרים מחדש.
- **שליטה**: משטח מגע והקלדה מהטלפון (שירות נגישות), או עכבר Bluetooth.

## הורדה
https://github.com/idanamos-jpg/idana/releases/latest/download/Lumo.apk

## הפעלה ראשונה
1. מתקינים, מחברים את המשקפיים, ושולחן העבודה עולה עליהם.
2. הגדרות ← נגישות ← "Lumo – שליטה במשקפיים" ← הפעלה. אם ההפעלה חסומה: פרטי אפליקציה ← ⋮ ← "אפשר הגדרות מוגבלות".
3. כדי שהחלונות יקבלו את הגודל שבחרתם: אפשרויות מפתח ← "אפשר חלונות בגודל משתנה" ו"אלץ פעילויות להיות ניתנות לשינוי גודל", ואז מפעילים מחדש את הטלפון.
