# XR Space

אפליקציית אנדרואיד למשקפי XREAL Air / Air 2 / Air 2 Pro, בדומה ל-Nebula:

- **מסך קבוע במקום (3DoF)**: החלונות נשארים במקומם כשמזיזים את הראש. המידע מגיע מחיישן התנועה של המשקפיים דרך USB.
- **כמה חלונות צפים**: אתרים, מסך בית ושיקוף של מסך הטלפון.
- **מסך מעוקל**: שליטה בעיקול, במרחק ובגודל של כל חלון.
- **מסך בית**: אתרים, חיפוש ורשימת האפליקציות שבטלפון.
- **הטלפון כשלט**: משטח מגע, מקלדת וכפתורי שליטה.

## הורדה

## התקנה
1. פותחים את הקישור בטלפון ומורידים את הקובץ.
2. פותחים את הקובץ ומאשרים "התקנה ממקורות לא ידועים".
3. מחברים את המשקפיים. מאשרים גישת USB ל-XR Space, ואפשר לסמן "השתמש כברירת מחדל".
4. אם סמסונג מציעה DeX, בוחרים בשיקוף מסך או סוגרים את ההצעה. בהגדרות של DeX כדאי לכבות הפעלה אוטומטית בחיבור מסך.

## שימוש
- **אצבע אחת**: הזזת הסמן. **הקשה**: לחיצה.
- **לחיצה ארוכה וגרירה**: הזזת חלון.
- **שתי אצבעות**: גלילה. **צביטה**: שינוי גודל החלון.
- **◎ מרכוז**: הכיוון שאליו מסתכלים עכשיו נקבע כמרכז.
- **"מסך קבוע במקום"** מסומן: מצב 3DoF. לא מסומן: המסך נעול לראש, ו"חלון הבא" עובר בין החלונות.
- **⚙ הגדרות**: אם התנועה הפוכה, מסמנים "הפוך כיוון". יש שם גם כיול חיישן ושדה ראייה.
